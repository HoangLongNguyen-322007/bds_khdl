[ĐOẠN CODE MINH HỌA]
def audit_data(df):
    print("1. KÍCH THƯỚC BẢNG:", df.shape)
    print("2. KIỂU DỮ LIỆU TỪNG CỘT:")
    df.info()
    print("3. TỔNG SỐ Ô BỊ TRỐNG:")
    print(df.isna().sum())
    print("4. TỔNG SỐ DÒNG BỊ TRÙNG LẶP:")
    print(df.duplicated().sum())

[GIẢI THÍCH CHI TIẾT TỪNG DÒNG CODE]
- def audit_data(df): Câu lệnh dùng để tạo ra một công cụ mới mang tên 'audit_data'.
- df.shape: Quét và đếm xem bảng dữ liệu có tổng cộng bao nhiêu dòng (căn nhà) và bao nhiêu cột (đặc điểm).
- df.info(): Kiểm tra xem máy tính đang nhận diện các cột là kiểu Chữ hay kiểu Số. Rất quan trọng để phát hiện lỗi định dạng.
- df.isna().sum(): Tìm các ô bị bỏ trống (isna) và cộng dồn lại (sum). Giúp ta biết cột nào đang thiếu thông tin trầm trọng nhất.
- df.duplicated().sum(): Đếm xem có bao nhiêu tin rao bán bị copy giống hệt nhau 100%.

[ĐOẠN CODE MINH HỌA]
import unicodedata

def normalize_vn(text):
    if pd.isna(text): return text
    
    text = str(text) 
    text = unicodedata.normalize('NFC', text)
    
    return text.lower().strip()

[GIẢI THÍCH CHI TIẾT TỪNG DÒNG CODE]
- if pd.isna(text): Kiểm tra nếu ô dữ liệu bị bỏ trống thì bỏ qua, không xử lý để tránh báo lỗi.
- str(text): Ép dữ liệu về dạng Chuỗi văn bản để an toàn.
- unicodedata.normalize('NFC', text): Ép toàn bộ các kiểu gõ tiếng Việt về chung một chuẩn duy nhất là NFC. Sửa dứt điểm lỗi font chữ.
- text.lower(): Ép tất cả các chữ cái thành viết thường 100%.
- text.strip(): Gọt bỏ mọi dấu cách (khoảng trắng) dư thừa ở đầu và cuối chữ.

def clean_price(x):
    if pd.isna(x): return np.nan
    
    s = str(x).lower().replace('triệu/m²', '').replace('triệu/m2', '').replace(',', '.').strip()
    
    try: 
        return float(s) 
    except: 
        return np.nan

df['Giá_m2_trieu'] = df['Giá/m2'].apply(clean_price)

[GIẢI THÍCH CHI TIẾT TỪNG DÒNG CODE]
- Lệnh replace('triệu/m2', ''): Xóa cụm từ văn bản đi kèm bằng cách thay thế nó bằng một chuỗi rỗng.
- Lệnh replace(',', '.'): Đổi dấu phẩy thành dấu chấm. Bước này bắt buộc vì chuẩn quốc tế dùng dấu chấm cho số thập phân (Ví dụ 2.5), nếu để dấu phẩy phần mềm sẽ báo lỗi.
- Lệnh float(s): Lệnh quan trọng nhất, ép cụm từ "2.5" (đang bị coi là chữ) thành Con Số Thực 2.5 để có thể làm toán (cộng trừ nhân chia).

--- SLIDE 13: BƯỚC 5.1 - LÝ THUYẾT GIÁ TRỊ NGOẠI LỆ (OUTLIERS) ---
=========================================
[VẤN ĐỀ]
Tin ảo (nhà hẻm 10m2 bán 100 tỷ) là những điểm Ngoại lệ (Outliers). Nó kéo mức giá trung bình của cả quận vọt lên sai sự thật, làm hỏng mọi biểu đồ phân tích.

[CÁCH TRỊ BẰNG THỐNG KÊ (QUY TẮC IQR)]
1. Chia dữ liệu làm 4 phần. Tìm mức phân vị 25% (Q1) và 75% (Q3) để lấy ra phần đông phổ biến nhất của thị trường.
2. Dùng công thức toán học tính ra một "Mức Trần". Giá nhà nào vọt qua mức trần này đều bị coi là bất thường (tin ảo).

=========================================
--- SLIDE 14: BƯỚC 5.2 - KỸ THUẬT CẮT NGỌN (CLIPPING) NGOẠI LỆ ---
=========================================
[ĐOẠN CODE MINH HỌA]
Q1 = df['Giá_m2_trieu'].quantile(0.25)
Q3 = df['Giá_m2_trieu'].quantile(0.75)
IQR = Q3 - Q1
upper_bound = Q3 + 1.5 * IQR

df['Giá_m2_trieu'] = df['Giá_m2_trieu'].clip(lower=0, upper=upper_bound)

[GIẢI THÍCH CHI TIẾT TỪNG DÒNG CODE]
- Lệnh quantile(0.25) và (0.75): Dùng thuật toán để tìm ra các mốc giá trị của Q1 và Q3.
- upper_bound = Q3 + 1.5 * IQR: Công thức kinh điển của Thống kê để tính ra Mức trần (Upper bound) hợp lý của thị trường.
- Lệnh clip(lower=0, upper=upper_bound): Kỹ thuật "cắt ngọn". Thay vì xóa bỏ làm thất thoát dữ liệu, lệnh này sẽ quét qua toàn bộ, hễ thấy giá nào Đắt Hơn mức trần (upper_bound) thì nó sẽ ép giá đó lùi xuống Bằng Đúng với mức trần.

--- SLIDE 15: BƯỚC 6 - ĐÓNG GÓI BẰNG PIPELINE (SỐ HÓA HOÀN TOÀN) ---
=========================================
[ĐOẠN CODE MINH HỌA]
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder, RobustScaler
from sklearn.impute import SimpleImputer

num_transformer = Pipeline(steps=[
    ('imputer', SimpleImputer(strategy='median')), 
    ('scaler', RobustScaler())
])

cat_transformer = Pipeline(steps=[
    ('imputer', SimpleImputer(strategy='constant', fill_value='khong_ro')), 
    ('onehot', OneHotEncoder(handle_unknown='ignore', drop='first'))
])

[GIẢI THÍCH CHI TIẾT TỪNG DÒNG CODE]
- Lệnh Pipeline(...): Tạo ra một dây chuyền tự động hóa.
- Lệnh SimpleImputer: Trám các lỗ hổng còn sót lại. Nếu là Số thì trám bằng giá trị ở Giữa (median). Nếu là Chữ thì trám bằng chữ "khong_ro".
- Lệnh RobustScaler: Chuẩn hóa thang đo, ép các con số siêu to (tiền tỷ) và siêu nhỏ (số tầng) về chung một tỷ lệ chuẩn mực để phần mềm dễ tính toán.
- Lệnh OneHotEncoder: Số hóa văn bản. Phần mềm không biết đọc chữ "Quận Cầu Giấy", hàm này sẽ tự động biến chữ đó thành các cột chứa mã nhị phân 0 và 1. Dữ liệu lúc này sạch 100% và chỉ toàn là Số!
